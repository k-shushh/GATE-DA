GATE Lab, on your GitHub

A static HTML/CSS/JavaScript codebase. No build step or secret keys.

  1. Use the delivered gate-lab-source.zip and extract it completely.
  2. Create a repository named gate-lab (or your preferred short name). Upload the extracted contents, including .github/workflows/pages.yml and the entire dist folder.
  3. Use branch main, or change the workflow’s branch setting.
  4. In repository Settings → Pages, choose GitHub Actions as the publishing source.
  5. Push your files or run Deploy GATE Lab from the Actions tab. The workflow deploys dist/ directly.
Bring your progress. Export a JSON backup from the current site’s Downloads & backups page. Import it on the new GitHub Pages URL. Browser storage does not automatically move between sites.

Editing and local preview

Edit the files in dist/. Open dist/index.html directly, or run npm start for a local server. No package installation is needed. Run npm test for the content/model checks. The source README explains how to regenerate the PDFs and code packs.

Python and SQL execution download their runtimes from CDNs. The lessons, quizzes and visualizations themselves are static and work offline.
