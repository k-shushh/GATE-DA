Your notebook, on your GitHub.

Plain HTML, CSS and JavaScript. No frontend build or secret keys.

  1. Download and fully extract the source ZIP.
  2. Keep index.html, scripts, styles and downloads together in the repository root. This edition has no dist/ folder.
  3. Commit the updated files to your existing GATE-DA repository and push to its publishing branch.
  4. For branch-based Pages, choose Settings → Pages → Deploy from a branch, the publishing branch, and /(root). Keep .nojekyll.
  5. After GitHub finishes deployment, your existing Pages address serves the updated notebook.
Bring your progress. Export a JSON backup from Downloads & backups before moving between local preview and GitHub Pages. Import it at the destination. Browser storage is separate for each origin.

Local study and editing

Open index.html, or run python -m http.server 8767 --bind 127.0.0.1 in the extracted folder and visit http://127.0.0.1:8767/. Stop with Ctrl+C. The included README explains the code layout, tests and download generation.

Python and SQL execution load runtimes from CDNs. Lessons, quizzes, flashcards and visualizations work offline. Official paper links require internet.
